試聴は合成した音声を -20 LUFS（ITU-R BS.1770）に揃え、Hub のナレーション音量（既定 50%）を掛けて鳴らします。デモと同じ式です（ゲイン = 音量 / 100）。

エンジンの準備（AivisSpeech Engine）

  • PowerShell で実行し、試聴中は起動したままにします。インストール手順は hapbeat-demos の tools/tts/README.md。
  • Chrome / Edge では初回に「ローカル ネットワーク上のデバイスへのアクセス」の許可を求められることがあります。許可してから「接続確認」を押してください。
  • 「CORS で拒否」はエンジンが動いているが、このページのアドレスを許可していない状態です。上のコマンドで起動し直してください。

保存と次の手順

未保存の変更はありません

 

  1. hapbeat-demos フォルダで音声を生成します（変わった行だけ合成し直します）。Unreal のデモ（T-Rex Encounter / Safety Mill VR）は、先にエディタを閉じてください。
    powershell -File tools/tts/generate-all-voices.ps1
    一部のデモだけなら -Only trex,handdemo のように指定します。voice.json を変えたときは全デモを生成し直します。
  2. 各デモをビルドします。Unreal は上のコマンドが取り込みまで行います。Unity は WAV が Assets 下に入るので、次にエディタを開いたとき・ビルドしたときに取り込まれます。
