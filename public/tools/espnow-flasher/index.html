ESP-NOW オーディオ ファーム書き込み

M5Stack に、ESP-NOW でライブ音声を同報する送信機・受信機、または中継用のリピータのファームを書き込みます。 ビルド環境（PlatformIO 等）は不要です。USB でつないでボタンを押すだけです。

はじめに確認

  • Chrome / Edge のデスクトップ版でのみ動作します（Web Serial API を使用）。 Safari・Firefox・スマートフォンでは書き込めません。
  • 書き込み中は同じデバイスにつながる他のシリアル接続を閉じてください。 Hapbeat Studio・シリアルモニタ・Arduino IDE などが接続していると失敗します。
  • M5Stack Basic / Core2 は USB シリアル変換に CH9102 を使います。 デバイスが見つからない場合はドライバを入れてください → M5Stack ドライバ配布ページ

送信機

PA のライン出力を入力し、ESP-NOW で受信機へ同報します。

  • M5Stack Basic / Core2（ESP32）
  • M5Stack CoreS3 + Module Audio（ESP32-S3）

バージョン: 読み込み中…

このブラウザでは書き込めません。Chrome または Edge のデスクトップ版で開いてください。 安全でない接続では書き込めません（HTTPS が必要です）。

受信機（モニタ）

受信したストリームを画面の波形で表示し、スピーカーのある機種では音も鳴らします。 スピーカーの無い機種は表示のみで動作します。

  • M5Stack Basic / Core2（ESP32・スピーカーあり）
  • M5Stack CoreS3 / Cardputer（ESP32-S3・スピーカーあり）
  • AtomS3 / M5Dial（ESP32-S3・表示のみ）

バージョン: 読み込み中…

このブラウザでは書き込めません。Chrome または Edge のデスクトップ版で開いてください。 安全でない接続では書き込めません（HTTPS が必要です）。

リピータ

送信機の ESP-NOW ストリームを中継し、受信機のカバー範囲を広げます。

  • M5Stack Basic / Core2（ESP32）
  • XIAO ESP32-C6（ESP32-C6・外部アンテナ）

バージョン: 読み込み中…

このブラウザでは書き込めません。Chrome または Edge のデスクトップ版で開いてください。 安全でない接続では書き込めません（HTTPS が必要です）。

手順

  1. M5Stack を USB でパソコンにつなぐ。
  2. 上のボタンを押す。
  3. ブラウザが出すシリアルポートの一覧から、該当するポートを選ぶ。
  4. 接続すると基板の種類が自動判別され、対応するファームが選ばれる。Install を選んで進める。
  5. 完了すると M5Stack が再起動する。

途中で止まる場合は、ケーブルを抜き差しし、他のシリアル接続を閉じてからやり直してください。

書き込みには ESP Web Tools （ESPHome / Nabu Casa, Apache License 2.0）を使用しています。
