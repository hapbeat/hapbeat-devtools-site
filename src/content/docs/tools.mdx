## メトロノームで触覚も鳴らす

1. `pipx install hapbeat-helper` で helper を入れる
2. helper を起動する
3. Web メトロノームを開き、「Hapbeat に触覚を送信する」をオンにする

helper 未接続でも音だけのメトロノームとして動きます（接続状態は画面下部に出ます）。
導入手順の詳細は [Helper のセットアップ](/docs/tools/helper/getting-started/)。
