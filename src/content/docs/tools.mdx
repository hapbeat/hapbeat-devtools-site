:::note
触覚を送るには **Runtime Consoleを開くPCでのhapbeat-helper起動 + Hapbeat実機** が必要です。
Web Runtimeはhelper未接続でもsession relayとイベント受信をシミュレーションでき、Webメトロノームは音声のみで動作します。
:::

## mod 設定エディタについて

このエディタは **Hapbeat 実機と、対応する mod を入れたゲーム**が揃ってはじめて意味を持ちます。
設定ファイル（`hapbeat_settings.json`）を持っていない状態で開いても、編集対象がないため何も表示されません。

- 設定ファイルは <a href="https://github.com/hapbeat/hapbeat-modkit" target="_blank" rel="noopener noreferrer">hapbeat-modkit</a> の mod がゲームフォルダに作ります（Pistol Whip なら `UserData\hapbeat_settings.json`、Muck なら `BepInEx\config\hapbeat_settings.json`）。
- ファイルはブラウザから直接読み書きします（アップロードされません）。File System Access API を使うため **Chrome / Edge のデスクトップ版**が必要です。
- 発火のライブ表示は mod が `127.0.0.1` に立てる診断用の配信を購読します。**HTTPS のこのページからでも `127.0.0.1` には繋がる**ので、繋がらないときはゲーム側が待ち受けていないだけです。

:::note[このページから開く場合の注意]
このホスト版を使うなら、`index.html` をローカルに落として `file://` で開く必要はありません。ブックマークしてそのまま開いてください。

ブラウザの保存領域は **ページのアドレスごとに分かれます**。以前ローカルの `file://` や `http://localhost` で使っていた場合、開いていたファイルの記憶とイベント履歴はこのページには引き継がれません。持ち越したい履歴は、旧ページの **「イベント履歴を書き出す」** で `hapbeat_event_workspace.json` を保存し、このページの **「イベント履歴を開く…」** で読み込んでください。
:::
