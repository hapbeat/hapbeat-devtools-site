## Adding haptics to the metronome

1. Install the helper: `pipx install hapbeat-helper`
2. Start it
3. Open the Web Metronome and turn on "Send haptics to Hapbeat"

Without the helper it still works as a sound-only metronome (the connection state is shown at the bottom of the page).
See [Helper setup](/en/docs/tools/helper/getting-started/) for the full instructions.
