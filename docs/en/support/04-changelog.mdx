## How you find out about updates

You don't have to come here — each tool tells you while you use it. **Once you dismiss a notice it is not shown again until an even newer version appears**, so pinning a version while you work never means dismissing the same message every session.

| Tool | How it tells you |
|---|---|
| **Studio** | A chip in the header when the connected Helper has a newer release; a chip in the device detail when a device has newer firmware |
| **hapbeat-helper** | One line at startup. `hapbeat-helper version` checks on demand (`--no-update-check` disables it) |
| **Unity SDK** | One Console line at Editor startup. `Hapbeat → Diagnostics → Check for SDK Updates` checks on demand |
| **Python SDK** | One line when you run the `hapbeat` command (`HAPBEAT_NO_UPDATE_CHECK=1` disables it) |
| **JavaScript SDK** | `npm outdated @hapbeat/sdk` |
| **Arduino** | The library update indicator in PlatformIO / Arduino IDE |
