:::caution[ベータ]
波形エディターのイベントパネル・AI 試行と、シーン確認タブは **ベータ機能** です。操作や保存形式（cue 表・作業フォルダの構成）は今後変わる可能性があります。
:::

このページは、ゲームのイベント（足音・咆哮など）に **音と触覚の素材** を割り当て、ゲームの録画に合わせて確認する機能の概要です。AI エージェントと一緒に素材を作る場合の前提もまとめています。

## 2 つのフォルダ

| フォルダ | 中身 | 開く場所 |
|---|---|---|
| **編集フォルダ** | 波形エディターの作業場所。クリップ、AI 試行と評価（`haptic-knowledge/`）、エージェントとのやり取り（`hapbeat-agent/`）、素材の調整データ（`adjust/`） | 波形エディターの「フォルダを開く」 |
| **ゲームプロジェクト** | cue 表（イベントごとの音・触覚の割り当て）、素材の WAV、録画（通し映像とイベントの発生時刻） | シーン確認タブの「プロジェクト」 |

`.hapbeat-editor/` は Studio の内部キャッシュです。読み書きしないでください（消えても再構築されます）。

## AI エージェントとの連携（MCP）

[hapbeat-helper](/docs/tools/helper/getting-started/) の `hapbeat-helper mcp` を MCP サーバーとして登録すると、AI エージェントは次の流れで Studio と協働できます。

1. `get_guide` で手順と書式を読む（編集フォルダの `hapbeat-agent/GUIDE.md` と同じ内容）
2. `submit_trial` で候補（試行）を出す
3. ユーザーが Studio で評価して **保存** する（保存が合図。別途「送信」はありません）
4. `wait_for_rating` で評価を受け取り、次の候補を作る

Studio からエージェントへの依頼（音の依頼・再作成・触覚へ進む・振り分けの変更）は、編集フォルダの `hapbeat-agent/outbox/` に書かれます。

## AI 試行と評価

- 候補ごとに ★（1〜5）とコメントを付け、試行全体にもコメントを書けます。コメントが主な情報源です。
- 場面のあるイベントは、録画の通し映像から代表の区間を切り出し、イベントの発生時刻どおりに試聴できます。
- 一覧はパネル上部の **プロジェクト** と **種類（音 / 触覚）** で絞り込めます。選択は次に開いたときも残るので、新しいプロジェクトの試行が見えないときはまずここを確認してください。
- 「保存して次へ」で確定します。★4 以上の候補はイベントの素材候補に **仮** として自動で追加され、★3 は控えに入ります。入力中の内容は自動で下書き保存されます。

## イベントパネル

ゲームの cue ごとに、音と触覚の素材を管理します。

- **素材プール**: 1 つのイベントに複数の素材を持てます。先頭（★）が **代表** で、エディタの試聴と単発の場面で使います。
- **グループと各強弱**: variant（強弱・状況）を持つイベントは、音と触覚それぞれについて、親のイベント（グループ）が素材を持つか、variant が自分の素材を持つかを表示で区別します。持たない側には状態やボタンを出さず「グループで指定」「各強弱で指定」とだけ示します。共有中の variant の「分ける」で親の今の★の素材がその variant に写り、その variant の「（親）と同じに戻す」で共有に戻ります（外した素材は控えに残ります）。親が素材を持たず各 variant だけが持つときは、親の「グループでまとめる」で各 variant の素材を親に集めます（先頭の variant の★が鳴り、ほかは★なしで残ります）。
- **★のないイベント**: 最後の★も外せます。★のない音・触覚はゲームで鳴らず、イベント一覧のそのイベントに ▲ が付きます。鳴らさないと決めたときは「なしにする」を押します（決定なので ▲ は付きません）。
- **仮 / OK**: 割り当てた素材は「仮」から始まり、確認したら「OK」にします。cue 表の変更はすべて自動保存されます。
- **調整**: 素材をその場でエフェクト（LPF など）と **強さスライダー** で調整します。変更はすぐイベントの WAV に反映され、元の音声とエフェクトは編集フォルダの `adjust/` に残ります。
- 試聴の触覚は、その cue の装着位置（首・手首など）に合うデバイスだけに送られます。

## エフェクト: ノイズ・整理

拾った音や生成した音の下処理に使うエフェクトです（エフェクト追加メニューの「ノイズ・整理」）。AI エージェントも試行の `effects` で使えます。

- **Spectral denoise（スペクトルノイズ除去）**: 周波数ごとに「いつも鳴っている量」（ノイズ床）を求め、その近くの成分だけを下げます。ローパスと違い打撃の高域は残り、サーッという定常ノイズだけが減ります。`thresholdK`（ノイズ床の何倍以下を下げるか、既定 2）、`floorDb`（下げる量、既定 −24 dB）、`percentile`（ノイズ床に使う下位パーセンタイル、既定 20 %）。
- **Isolate hit（打撃の切り出し）**: いちばん大きい打撃 1 回だけを残します。余韻が最大から `endDb`（既定 −50 dB）まで下がった所か、2 回目の立ち上がり（20 ms 以内に `riseDb`、既定 +9 dB）の手前で切り、`fadeMs`（既定 25 ms）でフェードアウトします。1 回の接触で 1 回だけ鳴る音にしたいときに使います。

## シーン確認タブ

録画に合わせて、cue ごとの全発生を確認します。

- **場面の倍率**（触覚の route gain・音の sfx.volume）は、このタブでだけ編集します（既定 1）。
- **揺らぎ**（素材の選び方、強さ・高さ・速さの揺らぎ）と **variant**（状況別の鳴らし分け）を編集できます。
- **音と触覚を組にする**: 音ごとに長さが違う場合、選ばれた音と同じ番号の触覚を鳴らします。
- 「この発生は別のイベントにすべき」は、エージェントへの依頼として送ります（cue 表には場面ごとの値を持ちません）。

## cue 表

cue 表（JSON）は、ゲームが実行時に読む **イベント → 音・触覚** の対応表です。Studio のイベントパネルとシーン確認タブはこの表を編集し、ゲームのビルド時に取り込まれます。Studio の外（エージェントなど）で書き換えられた場合は、項目単位で取り込まれます。

## 強さの 3 層

| 層 | 置き場所 | 編集する場所 |
|---|---|---|
| **形** | WAV（常にフルスケール、ピーク約 −0.5 dBFS） | エフェクト（イベントパネルの「調整」） |
| **素材の強さ** | 素材ごとの intensity（0〜1） | 強さスライダー（イベントパネルの「調整」） |
| **場面の倍率** | route gain / sfx.volume（既定 1） | シーン確認タブ |

最終的な出力は **WAV × intensity × 場面の倍率 × デバイス音量** です。エディタの試聴は WAV × intensity（場面の倍率は掛けない）、シーン確認タブの再生は場面の倍率まで掛けて鳴らします。
