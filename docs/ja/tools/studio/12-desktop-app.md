Hapbeat Studio デスクトップアプリは、Studio（Web）の画面に Helper を内蔵した Windows 用アプリです。Python・pipx・コマンド操作は要りません。

| | デスクトップアプリ版 | Web 版 |
|---|---|---|
| 必要なもの | アプリのみ | Chrome / Edge と [Helper](/docs/tools/helper/getting-started/)（Python・pipx） |
| 対応 OS | Windows 10 / 11 | Windows / macOS |
| ネットなしでの起動 | 前回保存した版で起動 | 不可 |

## 動作環境

- Windows 10 / 11（64 bit）
- インターネット接続（最新版の読み込みと更新に使います。つながらないときは前回保存した版で起動します）
- Hapbeat と同じ 2.4 GHz の Wi-Fi に PC をつなぐこと
- 初期設定・ファーム書き込みには、データ通信できる USB-C ケーブル（充電専用は不可）

## インストール

1. [ダウンロードページ](https://github.com/hapbeat/hapbeat-studio-desktop/releases/latest)から `HapbeatStudio-Setup-<ver>.exe` を入手して実行します。現在のユーザーにインストールされ、そのまま起動します（管理者権限は不要）。
2. 次回からは、デスクトップまたはスタートメニューの「Hapbeat Studio」から起動します。

### 初回だけ表示される確認

- **「Windows によって PC が保護されました」**: 署名のないアプリのため表示されます。「詳細情報」→「実行」を選んでください。
- **Windows ファイアウォール**: 「アクセスを許可する」を選んでください。許可しないと Wi-Fi 上のデバイスが見つかりません。
- **起動できない（スマート アプリ コントロール）**: Windows 11 でこの機能がオンの PC では、署名のないアプリは起動できません。「Windows セキュリティ」→「アプリとブラウザーの制御」→「スマート アプリ コントロールの設定」でオフにしてください。

## Web 版との違い

各タブの中身は Web 版と同じです。違いは次の点だけです。

- **表示するタブ**: Kit・UI・Manage を表示します。右上の「接続」から開くパネルで「すべての機能を表示する」をオンにすると、エディタとシーンのタブも表示されます。
- **右上の「接続」**: Web 版の「Helper」の位置にあります。押すとアプリのパネルが開き、内蔵 Helper の状態の確認・「Helper を再起動」・「ログのフォルダを開く」・「デバイス検出を再初期化」・「更新を確認」・表示の切り替えができます。
- **USB 接続**: Hapbeat を 1 台だけ USB でつないでいるときは、ポートの選択画面を出さずに自動で選びます。一度選んだポートは次回の起動後もそのまま使えます。
- **PC の音を流す**: Manage タブのデバイス一覧の下にある「PC の音を流す」で、この PC で鳴っている音（動画・ゲーム・音楽など）を選んだ Hapbeat の振動として流せます。

## 更新

- **Studio の画面**: 起動のたびにインターネットから最新版を読み込みます。開いている間に新しい版が出ると、右下に「再読み込みして更新」が表示されます（押すまでは切り替わりません）。
- **アプリ本体**（内蔵 Helper を含む）: 起動時に新しい版を確認し、裏でダウンロードした後に「再起動して更新」を表示します。「後で」を選んだ場合は、次にアプリを閉じたときに更新されます。

## オフライン

インターネットにつながらないときは、前回オンラインで起動したときに保存した版（初めての場合はインストーラーに含まれる版）で起動し、起動時にその旨を表示します。オフラインでは次の機能を使えません。

- Studio・アプリの更新
- ファームウェアの一覧（Wi-Fi・USB でのファーム更新）

## Helper について

- アプリの起動中は、内蔵の Helper が動きます。アプリを閉じると Helper も止まります。
- 内蔵の Helper は PC 内の決まった窓口（ポート 7703）を使うため、アプリの起動中は同じ PC のブラウザで開いた Studio も利用できます。
- [pipx で入れた Helper](/docs/tools/helper/getting-started/) がすでに動いている PC では、アプリはそちらを使います（パネルに「PC に別にインストールされた Helper を使用中」と表示）。内蔵の Helper に切り替えるには、ターミナルで `hapbeat-helper stop` を実行してください。数秒で内蔵の Helper が代わりに動きます。

## 困ったとき

| 症状 | 対処 |
|---|---|
| デバイスが一覧に出ない | PC と Hapbeat が同じ 2.4 GHz の Wi-Fi にいるか確認します。ファイアウォールの確認で許可しなかった場合は、Windows の設定で `hapbeat-helper` の通信を許可してください。パネルの「デバイス検出を再初期化」も試してください。 |
| 右上の「接続」が赤い | パネルを開き、「Helper を再起動」を押します。直らない場合は「ログのフォルダを開く」で `helper.log` を確認してください。 |
| USB でつないでも認識されない | 充電専用ではない、データ通信できるケーブルを使ってください。ほかの USB ポートも試してください。 |
| 起動しない | 上の「スマート アプリ コントロール」を確認してください。 |

ログは `%APPDATA%\Hapbeat Studio\logs` にあります。問い合わせの際は、このフォルダの中身を添えてください。

## アンインストール

Windows の「設定」→「アプリ」→「インストールされているアプリ」から「Hapbeat Studio」をアンインストールします。Kit などを保存した作業フォルダは削除されません。

## 対応 OS

Windows のみです。macOS では Studio（Web）と [Helper](/docs/tools/helper/getting-started/) を使ってください。
